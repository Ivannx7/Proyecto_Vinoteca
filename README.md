# 🍷 Vinoteca

Proyecto académico para la materia **Base de Datos I**, correspondiente al diseño e implementación de una base de datos relacional para un e-commerce de venta de vinos. Utiliza **Microsoft SQL Server** como motor de base de datos y **SQL Server Management Studio (SSMS)** como herramienta de administración y desarrollo.

## 📌 Descripción

Vinoteca es el modelo de datos de un sistema de venta online de vinos que permite gestionar el catálogo de productos (organizados por categoría y bodega), los clientes, los usuarios internos con distintos roles, las ventas con su detalle, los medios de pago y el historial de variación de precios. El proyecto abarca el modelado entidad-relación, la normalización de las tablas y la definición de las relaciones e integridad referencial entre ellas.

## 🎯 Objetivo del Proyecto

Diseñar e implementar, en el marco de la materia Base de Datos, una base de datos relacional normalizada que dé soporte a las operaciones principales de una vinoteca online. Puntualmente se busca:

- Modelar entidades y relaciones que representen correctamente el dominio del negocio (productos, categorías, bodegas, clientes, usuarios, ventas y pagos).
- Aplicar reglas de integridad referencial (claves primarias, claves foráneas y restricciones de unicidad).
- Registrar el historial de precios de los productos para trazabilidad.
- Administrar usuarios internos con distintos roles y permisos.
- Soportar múltiples métodos de pago por venta.
- Sentar las bases para el desarrollo de consultas, vistas, procedimientos almacenados y triggers sobre el modelo.

## 🛠️ Tecnologías utilizadas

- **Motor de base de datos:** Microsoft SQL Server
- **Herramienta de administración:** SQL Server Management Studio (SSMS)
- **Lenguaje:** Transact-SQL (T-SQL)
